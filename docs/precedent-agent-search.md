# 유사 사례 검색 MVP 검증

[로드맵](precedent-agent-roadmap.md) / [데이터 정의](precedent-agent-data.md)

21개 구간의 원본 스냅숏과 AI 모의 판단을 대조해 검색 인덱스를 만들었다. 검색 원천은 개발용 17개다. 평가용 4개는 질의와 검증에만 사용한다. 검색은 현재 사례와 같은 그룹 및 연장 계산이 질의 기준 시각까지 끝나지 않은 사례를 제외한다. 시연 기간 제외 여부와 원본 해시를 인덱스를 만들 때 확인한다.

## 검색 기준

현재 판단에서 중요한 제약 하나와 가능한 조치를 질의에 넣는다. 과거 사례의 핵심 제약과 조치는 후보 배치, 리스크 응답, 모의 판단에서 확인한 근거로 지정했다. 선택 근거를 찾는 질의와 보류·재계산 근거를 찾는 질의를 따로 처리한다.

| 제약 | 먼저 맞아야 하는 조건 | 결과에 표시하는 차이 |
|---|---|---|
| 탱크 재고 | 같은 탱크군, 상한·하한 방향, 적용 한계, 계획 또는 연장 구간, 한계 이탈 여부. 여유 차이 5%p 이내 | 상하한까지 남은 재고 여유 |
| 연속 접안 | 같은 시간 범위. 최소 교대 여유 차이 15분 이내, 연속 작업 수 차이가 두 배 이내 | 작업 수, 교대 여유, 선석 |
| 체선 임박 | 허용시간 여유 상태와 시간 범위. 여유 차이 2시간 이내 | 남은 정박시간, 선석 |
| 풍속 기준 확인 | 적용 부두군 및 비교할 하역 중단 풍속이 같음 | 당시 판정 근거와 이번에 확인할 예보·운영 기준 |
| 후보 미산출 | 기본안 반환 여부와 미산출 후보 수가 같음 | 과거 미산출 슬롯 및 이번에 확인할 계산 한도·호환 선석 |

표의 비교 폭은 프로토타입 검색 범위를 정하는 휴리스틱이다. 현재 사례에서 선석 변경이나 순서 조정이 확인돼야 해당 조치를 사용한 사례가 통과한다. 이렇게 남은 사례에서 수치 차이가 작은 순으로 정렬하고, 선석이 같으면 순위를 높인다. 그룹별 한 건, 전체 최대 세 건을 반환한다. 각 결과에 일치한 조건, 수치 차이, 이번 계획에서 확인할 항목, 과거 판단과 원본 근거 ID를 함께 제공한다.

풍속 비교에는 스냅숏에 저장된 운영 기준만 쓰고 사후 관측 풍속은 점수에 넣지 않는다. 판단과 재현에는 모의 입력 및 사후 자료가 포함된 경우가 있어 검색 호출과 결과에 모의 출처를 표시한다.

## 평가용 질의 결과

| 기준일 | 질의 | 결과 |
|---|---|---|
| 8월 10일 | 석유제품 반출 탱크 상한에 관한 선택 근거 | 0건. 같은 탱크·상한 조건의 9월 19일 기록은 기준 시각 이후 사례다. |
| 10월 3일 | 1-1의 8건 연속 접안에서 교대 여유 부족 | 5월 23일, 7월 27일, 2월 10일. 첫 결과는 연속 작업 5건이며 현재와 3건 차이가 난다. |
| 11월 23일 | 3~7번 부두에서 10 m/s와 14 m/s 중단 기준을 비교 | 5월 7일, 3월 23일의 보류 사례. 적용 기준을 먼저 확인하게 한다. |
| 12월 7일 | 기본안 없이 후보 2개가 빠진 상황 | 4월 19일의 재계산 사례. |

평가 질의 4개와 규칙 검사 17개를 통과했다. 반대 방향의 탱크 제약, 80%에서 75%로 바뀐 상한, 선석 변경 불가·미확인, 관련 후보 없음, 기준 시각 이후 자료, 평가 원천과 동일 그룹, 최대 세 건 반환을 검사했다. 이 결과는 정해진 조건에서 검색이 의도대로 동작하는지를 확인한 것으로, 전체 운영 사례에서의 정확도나 체선료 절감 효과 평가는 R09에서 다룬다.

## 재현

저장소 루트에서 실행한다. 검색 인덱스와 검증 기록은 로컬 출력 폴더에 보관한다. 현재 후보 화면에서 호출하려면 R08의 연결 작업을 진행한다.

```bash
base=../output/precedent-agent
python3 tools/real-data/build_precedent_search.py "$base/corpus-index.json" > "$base/search-index.json"
node tools/real-data/verify_precedent_search.mjs "$base/search-index.json" > "$base/search-verification.json"
```
