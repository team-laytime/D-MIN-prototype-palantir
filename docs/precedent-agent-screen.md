# 후보 비교 화면과 확정 판단 기록

[초기안 대조](precedent-agent-plan-audit.md) / [검색 검증](precedent-agent-search.md) / [로드맵](precedent-agent-roadmap.md)

후보 비교 화면에서 현재 계산 결과의 탱크, 연속 접안, 체선 임박, 비교 풍속을 기준으로 유사 사례를 조회한다. 사용자가 판단을 가르는 조건을 고를 수 있다. 재고 비교에는 위험 모델의 공통 경보 한계와 별도로 **해당 후보에 실제로 적용한 상하한**을 쓴다. 선석 이동을 쓴 사례는 현재 후보에 가능한 대체 배치가 있고, 스케줄러가 권한을 확인한 경우에 표시된다. 고정 선박을 옮겨야만 성립하는 조치는 확인 대상으로 열지 않는다.

현재 화면은 계획 입력의 설비 중단, 긴급 선적 마감, 고정 접안도 비교 조건으로 제공한다. 추가 유형의 기준과 브라우저 재생 결과는 [R12 추가 제약 검증](precedent-agent-r12.md)에 있다.

카드에는 당시 AI 모의 판단, 현재와 일치한 조건, 수치 차이, 다시 확인할 항목이 표시된다. **판단 기록에 참고**를 누른 사례만 확정 기록에 연결한다. 검색 제약·조치 조건 또는 후보 버전이 달라지면 참고 사례를 다시 선택하게 한다. 후보 비교에 근거를 제공하되 최종 확정은 기존 확정 경로에서 한다.

## 확정과 재시도

확정할 때 같은 계산의 A/B/C 정보, 화면 슬롯과 실제 프리셋, 엔진·요청·배치 식별자, 배치 및 리스크, 선택, 경합안, 사유, 참고 사례 근거 ID와 재검토 조건을 저장한다. 실제 계산 당시의 요청이 제공된 경우 그 요청을 그대로 사용한다. 같은 확정 요청 ID는 같은 버전에서 한 건만 저장한다. ID가 같은데 후보 버전이 다르면 저장을 중단한다. 브라우저 저장이 실패하면 확정을 반영하기 전에 오류를 표시한다.

확정 판단 기록과 취소 사실은 브라우저에서 다시 열 수 있다. 이용자 화면에는 기존대로 확정 일정이 제공되며, 판단 기록은 스케줄러 화면에서 확인한다. 팀 공용 저장과 브라우저 간 동기화는 운영 범위로 남아 있다.

## 검증

10월 3일의 저장된 팀 솔버·리스크 응답을 로컬 검증 화면에 연결했다. 1-1의 연속 작업 8건을 고른 상태에서 선석 변경 가능 여부를 확인하자 5월 23일, 7월 27일, 2월 10일 사례가 표시됐다. 5월 23일을 참고로 붙이고 확정 사유와 재검토 조건을 입력하자 확정 v1에 함께 표시됐다. 새로고침하고 다시 접속한 뒤에도 브라우저 판단 기록은 1건으로 확인됐다. UI 검증 환경에서는 로컬에 없는 IBM Plex 글꼴 가져오기를 임시로 제외했다.

저장 검증에서는 같은 요청 재시도, 버전 불일치 및 다른 역할 차단, 저장 실패 시 미확정, 취소 뒤 새 요청, 재접속 시 기록 보존을 검사했다. R07 검색 검증 결과도 다시 대조했다.

## R10 검색 결과 없음과 후보 미산출

현재 비교 조건의 확인 사항을 패널 상단에 표시한다. 유사 사례가 없거나 사례 인덱스를 불러오지 못했을 때도 확인 사항은 볼 수 있다. 카드별로 필요한 선석 변경 권한과 같은 추가 확인은 해당 카드에 둔다.

계획 생성에서 A가 미산출되면 A 배치를 이용하는 B는 미실행으로 표시하고, 독립적으로 계산할 수 있는 C는 실행한다. 비교 화면에서 A/B/C별 결과와 요청에 명시된 계산 한도를 보여준다. 후보 세트가 부족하면 재계산과 유사 사례의 재계산 근거만 제공한다. 서버 연결이나 응답 자체의 오류는 기존 계산 오류로 표시한다.

| 로컬 브라우저 재생 구간 | 확인한 결과 |
|---|---|
| 2025-12-07 | A 미산출, B 미실행 사유, C 산출을 확인했다. 계산 한도와 호환 선석 점검 안내가 표시됐고, 진단 참고 사례는 4월 19일이었다. 확정이나 판단 기록 첨부 버튼 없이 다시 계산할 수 있었다. |
| 2025-08-10 | 석유제품 반출 탱크 상한을 선택했을 때 검색은 빈 결과였고 승인 운영 한계, 최신 입출고와 재고 확인 안내를 표시했다. 12월 7일 상태는 남지 않았다. |

두 구간의 저장된 팀 솔버·리스크 응답을 로컬에서 재생했다. 현재 환경에 설치되지 않은 IBM Plex 글꼴은 검증 환경에서만 제외했다. `node --test src/lib/*.test.js`에서 16개 테스트가 통과했으며, 후보 세트 미산출 후 정상 세트 반환과 서비스 오류를 구분하는 경로도 포함했다.

```bash
base=../output/precedent-agent
python3 -B tools/real-data/build_precedent_search.py "$base/corpus-index-r11.json" --development-only > public/data/precedent-index.json
node --test src/lib/precedentDecision.test.js
node tools/real-data/verify_precedent_search.mjs "$base/search-index.json"
```

현재 화면 인덱스는 개발용 18개 모의 사례를 포함하며 로컬의 무시 경로 `public/data/`에 둔다. 평가용 11개 및 원본 엔진 스냅숏은 브라우저용 인덱스에 넣지 않는다.
