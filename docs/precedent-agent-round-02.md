# 유사 사례 추가 수집

[로드맵](precedent-agent-roadmap.md) / [첫 수집 라운드](precedent-agent-round-01.md)

첫 라운드의 12개는 강풍, 교대 여유, 탱크 상하한, 동일 배치 및 미산출을 포함했다. 두 번째 수집에서는 비교 가능한 후보를 더 확보하기 위해 입력 대상이 54~73건인 날짜를 골랐다. 평온한 날과 풍속 기준을 넘는 날, 달라진 선석 집중 양상을 포함하고 기존 사례의 계획 및 연장 구간과 겹칠 가능성이 낮은 날짜를 골랐다.

| 72시간 구간 시작일(09:00 KST) | 입력 접안 대상 | 최대 관측 풍속 | 구간을 고른 이유 |
|---|---:|---:|---|
| 2025-01-28 | 54 | 13.6 m/s | 비교적 적은 대상과 풍속 경계 |
| 2025-02-22 | 61 | 12.5 m/s | 2-6 선석에 집중된 구간 |
| 2025-03-23 | 60 | 14.65 m/s | 14 m/s 이상 5시간 |
| 2025-05-23 | 62 | 15.0 m/s | 14 m/s 이상 4시간 |
| 2025-06-09 | 65 | 11.4 m/s | 2-5와 1-1 선석에 집중된 구간 |
| 2025-08-10 | 59 | 8.05 m/s | 낮은 풍속의 하반기 평가 후보 |
| 2025-10-03 | 55 | 11.05 m/s | 2-6과 2-2 선석에 집중된 평가 후보 |
| 2025-12-07 | 73 | 13.25 m/s | 접안 대상이 많고 풍속이 기준에 가까운 평가 후보 |

관측 풍속은 날짜 선정용이며 당시 발행 예보는 미확인이다. 기준 시각이 시연 구간과 겹치면 실행하지 않는다. 솔버가 구간을 연장한 뒤 겹친 결과도 제외한다. 기존 라운드와 통합할 때 연장 구간이 겹치거나 동일 항차가 포함된 경우 같은 `case_group_id`로 묶고, 평가용 날짜는 해당 그룹 전체를 검색 원천에서 뺀다.

## 실행 및 판정 결과

추가 8개 중 6개에서 A/B/C와 리스크를 확보했고, 2월 22일과 12월 7일에는 미산출 후보가 남았다. AI 모의 판단은 선택 4개, 보류 2개, 재계산 2개다. 비교 가능한 7개는 팀 엔진으로 같은 풍속 기준에서 배치를 고정해 ETA 3시간 지연 및 하역 30% 연장을 비교했다. 하역 연장 재현의 재고 영향은 판정 대상에서 제외했다.

| 통합 결과 | 수량 |
|---|---:|
| 파일럿을 포함한 72시간 구간 | 21 |
| A/B/C와 리스크 확보 | 14 |
| 미산출 후보 포함 | 7 |
| 중복 방지 그룹 | 17 |
| 검색 원천 후보에서 뺀 평가 구간 | 4 |

8월 10일, 10월 3일, 12월 7일을 계산 전 평가용으로 지정했다. 통합 단계에서 11월 23일과 12월 7일이 같은 항차 그룹에 속해 두 날짜를 함께 평가로 분류했다. 시연용 날짜 4개와 겹친 결과는 없었다.

통합 인덱스는 `output/precedent-agent/corpus-index.json`에 있다. 판정 파일은 각 수집 라운드의 `ai-judgments.json`이고, 읽기용 정리는 같은 폴더의 `ai-judgments.md`다. 날짜를 추가할 때에는 검색에 부족한 제약과 선택·보류·재계산 유형을 먼저 확인해 보충한다. 날짜만 다르고 상황이 같은 구간은 하나의 그룹으로 센다.

## 추가 실행 방법

연간 입력을 다시 만들 필요 없이 날짜 목록으로 추가 수집을 실행한다. 기본은 짧은 탐색 설정이다. 탐색에서 미산출된 구간을 프로토타입 기본 설정으로 재실행할 때에는 별도 결과 폴더를 사용해 앞선 계산을 보존한다.

```bash
python3 tools/real-data/capture_precedent_round.py \
  --dataset public/data/real-2025.json --engine /path/to/team-engine \
  --python /path/to/python --output /path/to/round-02 --jobs 4 \
  2025-01-28 2025-02-22 2025-03-23 2025-05-23 2025-06-09 2025-08-10 2025-10-03 2025-12-07
python3 tools/real-data/summarize_precedent_round.py \
  /path/to/round-01 /path/to/round-02 /path/to/pilot-20250210/snapshot.json \
  --judgments /path/to/round-01/ai-judgments.json --judgments /path/to/round-02/ai-judgments.json \
  --evaluation-day 2025-08-10 --evaluation-day 2025-10-03 --evaluation-day 2025-12-07
```

통합 인덱스는 각 입력 폴더의 공통 상위 경로를 기준으로 원본 경로를 저장한다. 추가 사례도 원본 배치, 리스크 ID, 판단이 바뀌는 조건을 연결한다. 비용 비교 또는 조치 가능성 확인이 충분하지 않으면 보류나 재계산을 기록한다.
