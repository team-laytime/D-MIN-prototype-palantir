# R12 추가 제약의 유사 사례 검색 검증

[로드맵](precedent-agent-roadmap.md) / [R11 사례 수집](precedent-agent-round-03.md)

후보 비교 화면과 후보 미산출 화면에서 계획에 입력된 설비 중단, 긴급 선적 마감, 고정 접안을 검색 조건으로 고를 수 있다. 과거 사례는 개발용 18개 구간의 AI 모의 판단에서 찾는다. 평가용 11개 구간, 같은 항차·시간 그룹, 계산 구간이 기준 시각 뒤에 끝난 사례는 검색 원천에서 제외한다.

| 유형 | 검색 기준 | 현재 조치를 적용할 조건 |
|---|---|---|
| 설비 중단 | 영향 선석 수와 중단 중·예정 상태가 같아야 한다. 중단 길이 차이는 120분 이내이며 길이 비율도 최대 두 배다. 기준 시각부터 중단 시작까지의 차이는 360분 이내다. | 신규 접안 중단의 대체 선석 및 재고 위험을 확인하는 재계산 근거를 찾는다. 선석이 다르면 카드에 차이를 표시한다. |
| 긴급 출하 | `LOAD_BY`로 입력된 단일 자재의 톤 단위 물량을 비교한다. 자재 코드가 같고 마감까지의 시간 차이 360분 이내, 요청 물량 비율 최대 두 배여야 한다. | 현재 후보가 해당 요구 물량과 마감을 충족했고 스케줄러가 자재·물량·마감을 확인했을 때 선택 근거를 표시한다. 후보가 미산출된 경우 보류·재계산 근거만 조회한다. |
| 고정 접안 | 선석과 접안 시각을 그대로 고정한 조건을 비교한다. 기준 시각부터 고정 접안까지의 차이는 360분 이내다. | 같은 항차 집합을 배치하고 현재의 모든 고정 선석·접안 시각을 유지하면서 선행선 배치가 다른 후보가 있어야 한다. 스케줄러가 변경 권한을 확인하면 선택 근거를 표시한다. |

시간과 물량 비교 폭은 프로토타입 기준이다. 제약별 검색 결과가 없을 때도 확인할 조건을 표시한다. 후보 미산출 화면에서 과거 선택을 현재 확정 근거로 붙이는 기능은 제공하지 않는다.

## 평가 결과

| 평가일 | 조건 | 기대 결과 및 실제 결과 |
|---|---|---|
| 07-16 | 항공유 3,400t, 23:18 마감 | 0건. 4월 29일 선박용 경유 675t 선택 사례는 자재, 물량 및 조치가 다르다. |
| 08-04 | 2-4의 120분 신규 접안 중단, 연장 구간 탱크 위반 | 3월 15일의 중단 대응·탱크 위험 재계산 사례 1건. 선석 2-6과 2-4의 차이가 표시됐다. |
| 09-01 | 2-2의 120분 신규 접안 중단, 후보 B 미산출 | 3월 15일 재계산 사례 1건. 현재 대체 선석과 재고 영향을 확인하도록 안내했다. |
| 09-25 | 7번 19:55 고정 접안, 후보 B 미산출 | 0건. 6월 29일의 후보 C 선택은 현재 미산출 상태에서 적용할 재계산 근거가 아니므로 제외됐다. |

평가 4개 구간의 기대 결과가 검증용 전체 인덱스와 브라우저용 인덱스 모두에서 일치했다. 권한 미확인, 고정 선박을 움직이는 대안, 다른 자재·물량·마감, 이미 시작된 중단, 더 넓은 중단 범위, 계산 구간 종료 전 참조도 검사했다. 자동 검증 항목은 25개다.

로컬 브라우저에서 위 4개 평가 구간과 11월 15일 고정 접안 구간의 저장 솔버 응답을 재생했다. 11월 15일에는 권한을 확인하기 전에는 사례가 없었고, 확인 후 6월 29일 사례가 표시됐다. 일반 빌드는 로컬의 IBM Plex 글꼴 패키지 누락으로 실패했다. 브라우저 재생에서는 해당 글꼴 가져오기를 임시로 제외했다.

## 재현

```bash
base=../output/precedent-agent
python3 -B tools/real-data/build_precedent_search.py "$base/corpus-index-r11.json" > "$base/search-index-r12.json"
python3 -B tools/real-data/build_precedent_search.py "$base/corpus-index-r11.json" --development-only > public/data/precedent-index.json
node tools/real-data/verify_precedent_r12.mjs "$base/corpus-index-r11.json" \
  "$base/search-index-r12.json" public/data/precedent-index.json > "$base/search-verification-r12.json"
```

이번 검증은 4개 모의 평가 구간과 조건별 대조 실험의 규칙 적합성을 확인한다. 실제 체선료 절감액이나 판단 시간은 현장 실행·정산·업무 기록을 확보한 뒤 평가할 수 있다.
