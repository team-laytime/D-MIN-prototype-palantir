# D-MIN prototype guidelines

For changes that complete a task in [the precedent-agent roadmap](docs/precedent-agent-roadmap.md), check its stated acceptance criteria and run `python3 tools/real-data/update_precedent_roadmap.py` before finishing.

For a task requiring review or a separate run, record completion with `--complete TASK EVIDENCE` after verifying its evidence. If work is partial or required inputs are missing, keep the task open.
